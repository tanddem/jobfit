# Data Scientist

Meridian Health Analytics, Singapore

You will build and deploy machine learning models that predict patient
readmission risk for hospital networks across Southeast Asia.

## Requirements

- 3+ years building and shipping machine learning models
- Strong Python, including pandas and scikit-learn
- Deep learning with PyTorch or TensorFlow
- Solid statistics: hypothesis testing, regression, experimental design
- SQL for feature extraction
- Model deployment and monitoring in production
- MSc or PhD in Statistics, Computer Science or another quantitative field

## Nice to have

- MLflow or a similar experiment tracking tool
- Spark for large-scale data processing
- Healthcare domain experience
